# Teslo API

1. Clone project

2. Execute the command
``` yarn install ```

3. Clone the file ```.env.template``` and rename it to ```.env````

4. Change environment variables

5. Start database
```
docker-compose up -d
```

6. Start development mode

```yarn start:dev```
